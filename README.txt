MATIVA — A plain HTML, CSS and JavaScript website
================================================

GETTING STARTED
1. Keep all the folders together as shown below.
2. Open html/index.html in your web browser. No installation or server is needed.
3. Use the navigation to visit the other pages.

EDITING
HTML files hold page content. CSS holds all visual styling and screen-size rules.
The colors at the top of style.css control the whole website.
JavaScript holds navigation, the planner, contact validation, and project demos.
Comments explain the important sections. There are no external libraries or fonts.

PLANNER
Tasks live in an array for the current page session. Refreshing or leaving the
planner clears the list. Add, complete, delete, and filter tasks to try it out.

CONTACT
This is a practice form. It checks all fields, email format, a digits-only phone
number, and a message of at least 10 characters. Nothing is sent or saved.

PROJECTS
Click a project image or arrow to open its mini demo. The result calculator uses
sample grading thresholds, which are explained beside the calculator.

SAMPLE CONTENT
The portrait is AI-generated, not a real photograph of Adaora. Replace profile.jpg
with your own photograph, keeping the filename. Biography, skill percentages,
hobbies, and academic interests are editable sample text. "My University" is the
institution placeholder from the brief. Food venues and prices are fictional demo
content. GitHub and LinkedIn links currently point to the services' homepages;
replace them with your real profile URLs in each HTML file.

The study audio is an original synthesized musical loop. Project images are
original SVG mockups, so there are no missing image or audio dependencies.

This folder is the complete library-free website. Lovable's preview wrapper is
not included and is not needed to use or edit these files.
